
**Что делает:**
- Создает массив 1,000,000 элементов
- Вычисляет prefix sum на CPU (последовательно)

- Сравнивает результаты и время

**Ожидаемый результат:** GPU должен быть быстрее для больших массивов.

```bash
./task3

```

- Обрабатывает весь массив на CPU (OpenMP)

- Обрабатывает половину на CPU, половину на GPU ОДНОВРЕМЕННО
- Сравнивает все три подхода

**Ожидаемый результат:** Гибридный подход может быть fastest если CPU и GPU сбалансированы.

### Задание 4: MPI распределенные вычисления

```bash
# 2 процесса
mpirun -np 2 ./task4
# Или
make run4-2

# 4 процесса
mpirun -np 4 ./task4
# Или
make run4-4

# 8 процессов
mpirun -np 8 ./task4
# Или
make run4-8

# Запустить все тесты

```

**Что делает:**
- Создает массив 100,000,000 элементов (процесс 0)
- Распределяет между процессами (Scatterv)
- Каждый процесс обрабатывает свою часть
- Собирает результаты (Reduce)
- Выводит статистику масштабируемости

**Ожидаемый результат:** Ускорение с увеличением процессов, но не линейное.

## Описание заданий

### Задание 1: Вычисление суммы элементов массива (25 баллов)

**Цель:** Сравнить производительность CPU и GPU для операции редукции (суммирования).

**Реализация:**
- Последовательная сумма на CPU (цикл)
- Параллельная сумма на GPU (двухуровневая редукция)
  - Уровень 1: Каждый блок суммирует свою часть
  - Уровень 2: Суммируем результаты блоков
- Использование `atomicAdd` для безопасного сложения
- Размер массива: 100,000 элементов

**Ключевые концепции:**
- Reduction (редукция)
- Атомарные операции
- Двухуровневая агрегация

### Задание 2: Префиксная сумма с shared memory (25 баллов)

**Цель:** Реализовать scan (prefix sum) эффективно используя shared memory.

**Реализация:**
- Последовательный scan на CPU
- Параллельный scan на GPU
  - Scan внутри каждого блока (shared memory)
  - Scan сумм блоков
  - Добавление offset к блокам
- Размер массива: 1,000,000 элементов

**Ключевые концепции:**
- Prefix sum (scan)
- Shared memory для производительности
- Многоуровневый алгоритм
- Синхронизация потоков

### Задание 3: Гибридная программа CPU+GPU (25 баллов)

**Цель:** Показать когда гибридный подход эффективнее чем только CPU или только GPU.

**Реализация:**
- Операция: возведение в квадрат каждого элемента
- Вариант 1: Весь массив на CPU (OpenMP)
- Вариант 2: Весь массив на GPU
- Вариант 3: Половина на CPU, половина на GPU ПАРАЛЛЕЛЬНО
  - Использование CUDA streams
  - Асинхронное копирование
  - CPU работает пока GPU занят
- Размер массива: 10,000,000 элементов

**Ключевые концепции:**
- CUDA streams
- Асинхронные операции
- OpenMP для CPU
- Перекрытие вычислений и передачи данных

### Задание 4: MPI распределенные вычисления (25 баллов)

**Цель:** Изучить масштабируемость распределенных вычислений.

**Реализация:**
- Операция: квадрат + сумма
- Процесс 0 создает данные
- MPI_Scatterv распределяет данные
- Каждый процесс обрабатывает свою часть
- MPI_Reduce собирает результаты
- Тестирование с 2, 4, 8 процессами
- Размер массива: 100,000,000 элементов

**Ключевые концепции:**
- MPI инициализация и коммуникация
- Scatter/Gather операции
- Reduce для агрегации
- Масштабируемость
- Накладные расходы на коммуникацию
