### ✅ Задание 1 - Глобальная vs Разделяемая память
**Файл:** [task1_global_vs_shared.cu](task1_global_vs_shared.cu)

Реализованы две версии умножения массива на число:
- Версия 1: Использует только глобальную память GPU
- Версия 2: Загружает данные в shared memory (разделяемую память)

**Что демонстрирует:**
- Разница в скорости доступа к разным типам памяти
- Когда shared memory дает преимущество
- Использование `__shared__` и `__syncthreads()`

**Комментарии в коде объясняют:**
- Что такое глобальная и разделяемая память
- Как работает загрузка данных в shared memory
- Почему синхронизация важна
- Когда использовать каждый тип памяти

### ✅ Задание 3 - Коалесцированный доступ к памяти
**Файл:** [task3_coalesced_access.cu](task3_coalesced_access.cu)

Сравнение коалесцированного и некоалесцированного доступа к памяти.

**Две версии:**
- Версия 1: Коалесцированный доступ (соседние потоки → соседние адреса)
- Версия 2: Некоалесцированный доступ (stride паттерн)

**Что демонстрирует:**
- Огромная разница в производительности (10-30x!)
- Что такое коалесцированный доступ
- Почему паттерн доступа критически важен

**Комментарии объясняют:**
- Как GPU читает память блоками
- Почему соседние адреса быстрее
- Примеры хороших и плохих паттернов
- Визуализация доступа к памяти

## Особенности реализации

### Измерение времени
Используется `cudaEvent` для точного измерения времени GPU:
```cuda
cudaEvent_t start, stop;
cudaEventCreate(&start);
cudaEventCreate(&stop);
cudaEventRecord(start);
// ... ядро ...
cudaEventRecord(stop);
cudaEventSynchronize(stop);
cudaEventElapsedTime(&time, start, stop);
```

### Проверка результатов
Все программы проверяют корректность вычислений.

### Множественные прогоны
Для точности делается несколько прогонов и берется среднее время.

### Информативный вывод
Программы выводят:
- Параметры задачи
- Информацию о GPU
- Время выполнения
- Сравнительные таблицы
- Выводы и объяснения
